# Sales Data Analysis Project Task-1

## Project Overview

This project focuses on data cleaning, exploratory data analysis (EDA), SQL data extraction, and Power BI dashboard creation using a sales dataset.

## Tools Used

* Microsoft Excel
* MySQL
* Power BI
* GitHub

## Project Tasks Completed

* Data Cleaning
* Summary Metrics Creation
* Pivot Table Analysis
* SQL Queries
* Interactive Power BI Dashboard
* Business Insights Report

## Key Insights

* Highest sales generated from West Region
* Electronics category produced highest profit
* Higher discounts negatively affected profits
* December showed highest sales performance
